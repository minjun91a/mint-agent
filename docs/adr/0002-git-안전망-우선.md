# ADR 0002 — 리팩터 전 git 안전망 우선

- **상태(Status):** Accepted
- **날짜:** 2026-06-18
- **관련 Phase:** 0

## 맥락 (Context)

`youtube-agent`는 2026-04부터 운영 중인데 **버전관리(git)가 전혀 없었다.** 브리프 작업규칙은
"리팩터 단계에서 런타임 동작 불변 + 테스트로 동일성 보증"을 요구하는데, 버전관리 없이
리팩터하면 되돌릴 수가 없다. 또한 운영 코드에는 시크릿(`.env`·OAuth 토큰)과 352MB 생성
미디어(`output/`)가 섞여 있어, 그대로 커밋하면 비밀 유출·레포 비대 위험이 있다.

## 결정 (Decision)

리팩터/이식 착수 **전에** `youtube-agent`에 git 스냅샷을 만든다. 단:

1. `.gitignore`로 시크릿(`.env*`·`credentials/`·`*.pickle`)·`venv/`·`output/`·로그·백업 제외.
2. **커밋 전 스테이징을 검사하는 게이트**를 둔다 — 비밀/대용량이 잡히면 STOP.

   ```bash
   git diff --cached --name-only | grep -E '\.env|credentials/|\.pickle|^output/' && echo STOP
   ```

## 결과 (Consequences)

- ➕ 모든 리팩터의 되돌리기 기준점 확보(스냅샷 `705c0d3`, 150파일, 비밀 0건).
- ➕ 검증 게이트가 실제로 사고를 막음(아래 교훈).
- ➖ 시크릿은 git 밖에 남으므로 별도 백업·관리 필요.

## 교훈 (Learnings)

- `.gitignore`는 **인라인 주석 미지원** — `output/  # 주석`은 패턴 전체로 해석돼 매칭 실패.
  첫 스테이징에 `.env.bak`·`output/`이 섞였고, **커밋 전 검증 게이트에서 잡았다**.
- `.gitignore`는 **이미 추적된 파일에 적용되지 않는다** — 패턴 수정 후 인덱스를 비우고
  재스테이징해야 한다.
- → 자동화는 빠르게 틀린다. **비가역 행위(시크릿 커밋)는 실행 전 검증 단계를 끼운다.**
