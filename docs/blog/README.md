# mint-agent 개발 블로그

youtube-agent(운영 중인 1인 YouTube 자동화)와 신뢰 레이어(trust)를 **하나의 신뢰할 수 있는
멀티 에이전트 자동화 엔진 = mint-agent** 로 합쳐 가는 과정을 기록한다.

데모가 아니라 **운영 위에서 검증되는 시스템**을 만드는 것이 목표. 그 여정의 결정·실수·교훈을
주 1편 한국어로 남긴다. 각 글은 가능한 한 실제 커밋을 링크해 "글 ↔ 코드"를 묶는다.
