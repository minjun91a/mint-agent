# mint-agent 개발 블로그

youtube-agent(운영 중인 1인 YouTube 자동화)와 신뢰 레이어(trust)를 **하나의 신뢰할 수 있는
멀티 에이전트 자동화 엔진 = mint-agent** 로 합쳐 가는 과정을 기록한다.

데모가 아니라 **운영 위에서 검증되는 시스템**을 만드는 것이 목표. 그 여정의 결정·실수·교훈을
남긴다. 각 글은 가능한 한 실제 커밋을 링크해 "글 ↔ 코드"를 묶는다.

## 이 블로그 읽는 법

- **각 글은 독립적이다.** 순서대로 안 읽어도 이해되게 썼다 — 관심 가는 글부터 골라 읽어도 된다.
- **작업은 들쭉날쭉이지만 글은 주제로 묶는다.** 커밋은 시간순이라 산발적이지만, 아래 글은
  *phase가 아니라 문제(주제)*로 나뉜다. 한 편이 여러 커밋을 묶기도 한다.
- **처음이라면** #01(왜)로 큰 그림을 잡고 → #04(어떻게)로 최신 방법론을 보는 흐름을 권한다.
